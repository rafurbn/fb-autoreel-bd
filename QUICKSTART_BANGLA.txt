FB AutoReel BD - বাংলা ফেইসবুক রিলস কন্টেন্ট ইঞ্জিন
========================================================================

সতর্কতা: সব API-র ফ্রি টিয়ার আছে, কিন্তু কোটা সীমিত। "১০০% আনলিমিটেড" নয়।
         স্টক ভিডিও + AI ভয়েস দিয়ে বানানো কন্টেন্ট "মৌলিক" হিসেবে গণ্য হবে — এমন কোনো গ্যারান্টি নেই।

১. প্রস্তুতি:
   - Python 3.10+ ও FFmpeg (ffmpeg ও ffprobe PATH-এ থাকতে হবে) ইনস্টল করুন।
   - pip install -r requirements.txt

২. কনফিগারেশন:
   - .env.example ফাইলটি কপি করে .env নামে সংরক্ষণ করুন এবং আপনার Keys বসান:
     GEMINI_API_KEY (https://aistudio.google.com/apikey)
     FB_PAGE_ID এবং FB_PAGE_ACCESS_TOKEN (মেটা বিজনেস ম্যানেজার; pages_manage_posts + publish_video)
     PIXABAY_API_KEY (https://pixabay.com/api/ ; ব্যাকগ্রাউন্ড ভিডিওর প্রাথমিক উৎস)
     PEXELS_API_KEY (ঐচ্ছিক বিকল্প ভিডিও উৎস)
   - ঐচ্ছিক: TTS_VOICE, BRAND_NAME

৩. ব্র্যান্ড ফাইল (ঐচ্ছিক, না থাকলে পাইপলাইন চলবে):
   - assets/logo.png , assets/music/sample_bg.mp3 , assets/fonts/Kalpurush.ttf
   - বিস্তারিত: assets/README.md

৪. টেস্ট রান (ফেসবুকে পোস্ট ছাড়া শুধু ভিডিও তৈরি):
   python main.py --test
   আউটপুট দেখুন: output/final_reel_*.mp4

   API কী ছাড়াই সম্পূর্ণ ড্রাই রান (স্যাম্পল স্ক্রিপ্ট, কোটা খরচ নেই):
   python main.py --offline --test
   প্রোডাকশনে Gemini স্ক্রিপ্ট তৈরি করতে না পারলে পোস্ট হবে না; স্যাম্পল কেবল --offline মোডে ব্যবহৃত হয়।

৪খ. স্ক্রিপ্টের ধরন:  --category funny | motivation | lifestyle | story | news
   উদাহরণ:  python main.py --test --category motivation

৫. সরাসরি তৈরি ও ফেসবুকে পোস্ট:
   python main.py
   সফল হলে exit code 0, ফেইল হলে 1।

৫খ. টেস্ট চালাতে (কোড বদলালে আগে এটা চালান):
   pip install -r requirements-dev.txt
   python -m pytest

৬. প্রতিদিন ক্লাউডে অটো-পোস্ট:
   ক) প্রজেক্টটি GitHub Repository-তে পুশ করুন; workflow ফাইল default branch-এ থাকতে হবে।
   খ) Settings > Secrets and variables > Actions > New repository secret:
      GEMINI_API_KEY, FB_PAGE_ID, FB_PAGE_ACCESS_TOKEN, PIXABAY_API_KEY
      (PEXELS_API_KEY ও BRAND_NAME ঐচ্ছিক)
   গ) Actions ট্যাবে "Daily Automated Facebook Reel" workflow Enable করুন।
      "Run workflow" চাপলে ক্যাটাগরি বেছে নিতে ও "শুধু টেস্ট" দিতে পারবেন।
      test_only ছাড়া চালালে সেটি Facebook-এ সত্যিই পোস্ট করবে।
   ঘ) workflow প্রতিদিন UTC 03:00-এ চলে, অর্থাৎ বাংলাদেশ সময় সকাল 09:00-এ।
      GitHub Actions চালু থাকতে হবে।

   মনে রাখুন: কম্পিউটারের .env ফাইল GitHub Actions-এ যায় না; key-গুলো শুধু GitHub Secrets-এ যোগ করুন।
   secret কখনো source code-এ লিখবেন না বা public repository-তে .env আপলোড করবেন না।
