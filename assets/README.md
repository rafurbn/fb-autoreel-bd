# assets — ব্র্যান্ড ফাইল

এই ফোল্ডারে থাকা ফাইলগুলো কোড নিজে থেকে খুঁজে নেয়। কোনো ফাইল না থাকলে পাইপলাইন
থেমে যায় না, শুধু সেই অংশটা বাদ দিয়ে রেন্ডার হয়।

| ফাইল | কাজ | বাধ্যতামূলক? |
|------|------|-------------|
| `logo.png` | ভিডিওর কোণে ওয়াটারমার্ক (`BRAND_LOGO_PATH`) | না — না থাকলে শুধু টেক্সট ব্যানার থাকে |
| `music/sample_bg.mp3` | মৃদু ব্যাকগ্রাউন্ড মিউজিক (১৫% ভলিউমে মিক্স হয়) | না — না থাকলে ভয়েস একা |
| `fonts/Kalpurush.ttf` | বাংলা সাবটাইটেল ও ব্র্যান্ড ব্যানারের ফন্ট | না — না থাকলে সিস্টেমের Noto/Nirmala ব্যবহার হয় |

## নিজের ফাইল বসানোর নিয়ম

1. **লোগো:** ৪০০×৪০০ PNG (স্বচ্ছ ব্যাকগ্রাউন্ড ভালো), `assets/logo.png` নামে সেভ করুন।
2. **মিউজিক:** `.mp3`, `.m4a` বা `.wav` যেকোনো ফাইল `assets/music/`-এ `sample_bg` নামে রাখুন
   (নাম না মিললেও ফোল্ডারে একটাই অডিও থাকলে সেটা নেওয়া হয়)। লাইসেন্স-মুক্ত মিউজিক ব্যবহার করুন
   (যেমন Pixabay Music, YouTube Audio Library)।
3. **ফন্ট:** [Kalpurush](https://fonts.google.com/specimen/Kalpurush) বা যেকোনো বাংলা TTF
   `assets/fonts/Kalpurush.ttf` হিসেবে রাখুন।

> রিপোতে দেওয়া `logo.png` ও `sample_bg.mp3` শুধু **প্লেসহোল্ডার** — এগুলো নিজের ব্র্যান্ড ফাইল
> দিয়ে বদলে নিন।

## ফন্ট কেন গুরুত্বপূর্ণ

libass (FFmpeg-এর `subtitles` ফিল্টার) ফন্ট খোঁজে ফন্ট **পরিবার-নাম** দিয়ে (যেমন
`Kalpurush` বা `Noto Sans Bengali`), ফাইল-পাথ দিয়ে নয়। `assets/fonts/`-এ ফন্ট থাকলে কোড
সেই নামটাই ব্যবহার করে, নাহলে fallback হিসেবে `Noto Sans Bengali` ধরে। GitHub Actions-এ
`fonts-lohit-beng-bengali` ইনস্টল হয়, তাই Linux-এ কাজ করবে।
