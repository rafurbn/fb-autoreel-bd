# FB AutoReel BD - ১০০% ফ্রি ও অটোমেটেড ফেইসবুক রিলস কন্টেন্ট অটোমেশন

এই প্রজেক্টটি প্রতিদিন স্বয়ংক্রিয়ভাবে ট্রেন্ডিং বাংলা স্ক্রিপ্ট তৈরি করে, মানুষের মতো ন্যাচারাল ভয়েসওভার যোগ করে, ফেইসবুকের "Unoriginal Content" পলিসি এড়াতে ডায়নামিক কালার গ্রেডিং ও বাংলা সাবটাইটেল রেন্ডার করে এবং সরাসরি আপনার ফেইসবুক পেজে রিলস হিসেবে আপলোড করে।

## বিশেষ সুবিধাসমূহ
1. **১০০% ফ্রি:** কোনো পেইড এপিআই বা সার্ভার ভাড়া নেই।
2. **ক্যাপচামুক্ত:** ব্রাউজার অটোমেশন না থাকায় ব্লক বা ক্যাপচায় আটকে যাওয়ার ভয় নেই।
3. **মনিটাইজেশন প্রোটেকশন:** নিজস্ব ওয়াটারমার্ক, ডায়নামিক সাবটাইটেল এবং FFmpeg কালার ফিল্টারের কারণে ভিডিও মৌলিক (Original) হিসেবে গণ্য হয়।
4. **সার্ভারলেস ফ্রি শিডিউলিং:** GitHub Actions দিয়ে ক্লাউডে প্রতিদিন স্বয়ংক্রিয়ভাবে চলে।

## লোকাল সেটআপ
```bash
git clone <repo_url>
cd fb-autoreel-bd
pip install -r requirements.txt
cp .env.example .env
# .env ফাইলে API Keys বসিয়ে নিন
python main.py --test  # টেস্ট রান (ফেসবুকে পোস্ট ছাড়া)
python main.py         # সরাসরি তৈরি ও ফেসবুকে পোস্ট
```
